# Andrés Lira — Ingeniería de sistemas y arquitectura backend

Sitio de una sola página desarrollado para el Taller Integrador (Actividad 3, 4%)
de Ingeniería Web I: HTML5 semántico, CSS Flexbox responsivo y formulario accesible.

## Estructura

- `index.html` — marcado semántico (header/nav, main con tres `<section>` ancladas,
  `<article>` para cada proyecto, `<address>`, footer).
- `styles.css` — hoja de estilos organizada por tokens, base, componentes,
  secciones y breakpoints (móvil primero, con puntos de quiebre en 640px y 1024px).

## Cómo verlo

Abrir `index.html` en el navegador, o servirlo con cualquier servidor estático
(por ejemplo, la extensión "Live Server" de VS Code).

## Validación

El HTML y el CSS fueron pensados para pasar sin errores críticos en el
[validador W3C](https://validator.w3.org).
